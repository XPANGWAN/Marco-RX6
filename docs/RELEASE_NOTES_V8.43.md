# MARCO RX6 8.43
رمز الإصدار: 60

## ما الجديد؟
- إصلاح الضغط على إشعار تحديث التطبيق لفتح صفحة التحميل الرسمية مباشرةً في المتصفح، دون فتح واجهة MARCO أولاً.
- الإبقاء على فتح إشعارات الألعاب وبقية الإشعارات داخل التطبيق.
- الحفاظ على منع تكرار إشعار الإصدار نفسه.

## شرح التحديث ببساطة
عند الضغط على إشعار توفر تحديث جديد، سيفتح المتصفح صفحة التحميل الرسمية مباشرةً. لن تحتاج إلى الدخول إلى MARCO ثم الانتقال إلى الموقع.

## English
- App-update notification taps now open the official download page directly in the browser, without opening the MARCO interface first.
- Game and other notifications continue to open inside the app.
- Duplicate notifications for the same release remain suppressed.

## Français
- Les notifications de mise à jour ouvrent désormais directement la page officielle de téléchargement dans le navigateur, sans ouvrir d’abord l’interface MARCO.
- Les notifications de jeux et les autres notifications continuent d’ouvrir l’application.
- La protection contre les notifications en double pour une même version est conservée.

## Español
- Al tocar una notificación de actualización, ahora se abre directamente en el navegador la página oficial de descarga, sin abrir primero la interfaz de MARCO.
- Las notificaciones de juegos y otros avisos siguen abriendo la aplicación.
- Se mantiene la protección contra notificaciones duplicadas de una misma versión.
