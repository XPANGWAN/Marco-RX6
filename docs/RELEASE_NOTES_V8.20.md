# MARCO RX6 — V8.20

## 🇸🇦 العربية

### أبرز التحديثات
- تحسين التوافق مع روابط التحميل الخارجية مع الحفاظ على الروابط الأصلية.
- إصلاح معالجة صفحات التحميل المعروفة دون تغيير روابط التحميل المباشرة.
- الحفاظ على روابط NoPayStation وبقية مواقع التحميل كما هي.
- تحديث التطبيق إلى الإصدار **8.20** ورمز الإصدار **37**.

### ملفات APK
أرفق ملفات APK الثلاثة التي ينتجها GitHub Actions:
- `app-arm64-v8a-release.apk`

- `app-universal-release.apk`

### التثبيت

## 🇬🇧 English

### Highlights
- Improved compatibility with external download links while preserving original URLs.
- Fixed handling of known download pages without rewriting direct download links.
- Preserved NoPayStation links and links from other supported download sites.
- Updated the app to **version 8.20**, version code **37**.

### APK files
Attach the three APK files produced by GitHub Actions:
- `app-arm64-v8a-release.apk`
- `app-armeabi-v7a-release.apk`
- `app-universal-release.apk`

### Installation
Install the APK matching your device over the existing app. Do not uninstall the current version.
